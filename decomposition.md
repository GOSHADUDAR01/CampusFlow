## 4. Семантическая структура

Для данного проекта логично использовать следующую структуру:

- `header` — шапка с брендом CampusFlow, навигацией и поиском;
- `nav` — основная навигация по разделам: каталог, мои события, профиль;
- `main` — главная область страницы, куда помещается основной контент;
- `section` — блоки каталога, фильтров, активности и формы регистрации;
- `article` — карточка мероприятия как самостоятельная смысловая единица;
- `aside` — боковая панель фильтров на desktop и мобильные фильтры в раскрываемом меню;
- `form` — форма регистрации, где поля сгруппированы логически;
- `footer` — в перспективе может содержать ссылки на справку и правила, но в текущем макете может отсутствовать.

Такой выбор гарантирует устойчивую семантическую модель, лучшее доступность и простую поддержку в дальнейшей разметке и стилях.

## 5. Адаптивность

- При ширине ~1024 px: уменьшается количество колонок карточек, фильтры переходят в компактную компоновку, расстояния внутри карточек сокращаются.
- При ~768 px: контент перестраивается в 2 колонки или в одну колонку в зависимости от плотности, боковая панель фильтров становится раскрываемой панелью/диалогом.
- При ~375 px: весь макет переходит в одну колонку без горизонтальной прокрутки; шапка складывается в компактную навигацию, поля формы становятся полноширинными, строка поиска растягивается на всю ширину.

Для мобильной версии предпочтительно использовать sliding panel или dialog для фильтров: это сохраняет доступность, не перегружает экран и позволяет быстро очистить/применить фильтры без потери контекста.
