# CampusFlow

Платформа для поиска и регистрации на учебные мероприятия.

## Запуск

```bash
npm install
npm run dev
```

## Проверка качества

```bash
npm run lint
npm run lint:css
npm run format:check
npm run build
```

## Структура проекта

```text
src/
  data/
    events.js
  main.js
  style.css
public/
.decomposition.md
README.md
```

## Основной сценарий

Пользователь открывает каталог мероприятий, применяет фильтры, выбирает событие, изучает детали и отправляет заявку на участие.
